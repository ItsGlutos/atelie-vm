# Ateliê VM — site

Site institucional e catálogo do **Ateliê VM — Artesanato em resina**: peças em resina
com flores silvestres prensadas, feitas à mão.

Visual alinhado à logo do ateliê: paleta creme, rosa-poeira e sage, selo circular com o
monograma VM, tipografia serifada (Playfair Display), script (Parisienne) e ilustrações
botânicas vetoriais próprias.

## Páginas

- `index.html` — versão desktop (também adapta para telas menores)
- `celular.html` — versão mobile dedicada
- `source/` — arquivos originais do editor de design (`.dc.html`)

## Conteúdo

- Hero com selo "peça única"
- Fita de materiais e técnicas
- Coleção com 6 peças ilustradas
- Encomenda sob medida com briefing interativo
- Processo em 4 etapas
- Diário do ateliê e rodapé completo

## Rodando localmente

Basta abrir `index.html` no navegador, ou servir a pasta:

```bash
python -m http.server 8899
```

Acesse `http://localhost:8899`.
